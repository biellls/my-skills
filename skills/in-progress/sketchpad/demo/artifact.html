Can a sketch make an agent's disagreement useful?

Human supplies
intent, taste, judgment
Agent supplies
examples, alternatives, consequences

This browser workspace puts a concrete idea beside a native scene. A human can select this sentence, leave an anchored comment, and keep talking while the existing Claude Code session waits in its terminal.

The small loop is: wait → receive → inspect → act → reply. A proposal is a hypothesis, never a silent mutation.
Material caveat: a stopped agent cannot be awakened by localhost polling, and terminal permissions still apply. The browser is not a second brain.
