---
name: step-by-step
description: Turn a grilling session into step-by-step alignment, one step at a time from the root.
disable-model-invocation: true
---

Align with the user one **step** at a time: a single idea, in a few plain sentences, with your recommendation. Then wait.

- Start from the root concept. Each bite builds only on steps already agreed.
- Name everything you mention in words the user has already seen; define a term before using it.
- When an agreed step reveals structure, show that slice of the model as a small ASCII diagram before the next step.
- Send fact-finding, best-practice checks and second opinions to sub-agents; bring back only the answer.

Done when nothing in the design tree is left unagreed. Then summarise the whole for one final confirmation.
